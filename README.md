# experiment-report-skill

从已完成的实验材料创建课程风格实验报告 LaTeX 项目。遵循严格的来源限界和面向读者的写作约束，将实验资产（代码、日志、图表、数据等）转换为 Overleaf 就绪的报告包。

## 目录结构

```
experiment-report-skill/
├── SKILL.md              # 主技能定义，含完整工作流与写作约束
├── openai.yaml           # opencode 技能注册入口
├── README.md             # 本文件
├── report/               # 【示例产出】真实运行得到的报告项目，安装时排除
│   ├── main.pdf          #   编译完成的 PDF 报告
│   ├── main.tex          #   LaTeX 源文件
│   └── figures/          #   图表资产
└── references/
    ├── source-recovery.md     # 材料恢复（PDF 提取、文本编码处理等）
    ├── evidence-grounding.md  # 证据支撑规则（声称模式、典型证据来源）
    ├── report-structure.md    # 默认报告结构（章节顺序与指导）
    └── final-review.md        # 交付前审阅清单（可读性、语言、编译检查）
```

## 核心工作流

| 步骤 | 说明 |
|------|------|
| 0. 检查实验讲义 | 若存在教师下发的实验手册/评分标准，逐项核对材料完整性；不完整则中止 |
| 1. 恢复原始材料 | 确保笔记、PDF、截图、图形等均可读；提供 pypdf 提取等恢复模板 |
| 2. 证据挖掘 | 将材料分组为背景/方法/设置/结果/分析/结论，每项声称绑定具体来源 |
| 3. 为读者而写 | 以从未见过中间过程的教师视角写作，删除演示者语言和流程笔记 |
| 4. 从材料构建 | 以实验材料为内容边界，不编造结果或结论 |
| 5. 默认结构 | 采用"目的 → 方法与实现 → 设置 → 结果 → 分析 → 结论"的标准六段式 |
| 6. 代码补全类实验 | 仅当明确要求时启用，用任务叙述替代纯摘要式结果 |
| 7. 术语与公式 | 首次出现时定义新术语和符号，每张图表配局部解释 |
| 8. 本地编译 | XeLaTeX 编译通过 → 死资产检查 → 生成 Overleaf 包 |
| 9. 合规审计 | Pass A（叙述声音+分析深度）→ Pass B（Oracle 全约束合规审计），两轮顺序执行 |

## 依赖

### 编译环境

- **XeLaTeX** — 本地编译 `main.tex`，需安装 TeX 发行版（TeX Live / MiKTeX）
- **bibtex**（可选）— 当报告包含 `.bib` 参考文献文件时需要
- **Overleaf**（可选）— 在线编译交付，当本地缺少 XeLaTeX 时代替

### opencode 运行时或者其他 Coding Agent 系统

- **explore / fast 子代理** — Pass A 审计（叙述声音与深度快速扫描）
- **oracle / 高负载子代理** — Pass B 审计（全量约束合规性判断）
- **task 系统** — 所有子代理通过 opencode 的 task 调度

### Python 库（材料恢复阶段）

- `pypdf` — 从 PDF 实验材料中提取文本和表格内容
- 或者 MuPDF 等其他 PDF 提取工具

### 无外部依赖

- 不依赖任何第三方 LaTeX 模板或样式文件
- 报告由 skill 根据材料自动生成，无需预先准备模板

## 使用方式

1. 确保实验已完整完成，所有材料（输出、日志、图表等）准备就绪
2. 调用 skill：`/experiment-report-skill`
3. 最好提供实验材料路径，skill 将按九步工作流自动生成报告
4. 交付物为可直接上传 Overleaf 的 LaTeX 项目包，主入口为 `main.tex`

## 关键写作约束

- **实验者视角**：以"我们做了什么"叙述，非"算法是什么"的教科书语气
- **面向教师**：不假设教师见过任何内部工作产物（笔记本、日志、聊天记录）
- **禁止列表**：报告正文使用散文而非项目符号列表（物料清单等真正枚举除外）
- **证据边界**：声称不超过实验材料能支撑的范围；分析推进到材料允许的最大深度
- **专业而详尽的流畅行文**：专业（非口语化）、详尽（非电报式缩写）、流畅（逻辑自然承接）

## 示例产出

`report/` 目录包含一份使用本技能生成的完整示例报告，主题为「本地文本文件词频统计分析」。该报告由 **OpenCode + DeepSeek V4 Pro** 自动生成，辅以少量人工干预（字体配置调试与合规审计修复），可供查阅 `report/main.pdf` 了解报告成品效果。

`report/` 仅为示例目录，**安装本技能时应将其排除**（不复制到目标 skill 目录）。技能加载后，Agent 会根据用户提供的实验材料从零生成新的报告，无需依赖此示例。

## 安装注意

安装技能时，需向用户询问以下身份信息以填入报告作者字段（对应 SKILL.md 第 78 行的 `<单位> <姓名> <学号>` 模板）：

- 单位（如学院或学校名称）
- 姓名
- 学号

若用户不提供，报告将以中性占位符「单位 姓名 学号」呈现。
