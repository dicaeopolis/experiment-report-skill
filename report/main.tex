\section{实验目的}

本实验以词频分布分析为工具，对本地项目中的一组 Markdown 文档进行了系统的统计刻画，旨在从定量角度揭示这份语料的词汇使用模式和内部结构。

实验的具体目标分为三个递进的层次。第一，建立可同时处理中英文混合文本的分词与统计工具链，产出词频、N-gram 词组频率和 TF-IDF 关键词等多维统计量，使分析结果可复现。第二，将统计结果转化为柱状图、直方图、词云和跨文件热力图等可视化图表，使词频的分布形态可以直观呈现。第三，通过 Zipf 定律验证（该定律预测自然语言文本中词频与排名在双对数坐标中呈斜率接近 \(-1\) 的线性关系）和累积覆盖率分析，定量检验该语料的统计规律性，并结合各文件间的词频差异，揭示语料的内部主题结构。

\subsection{语料选择}

我们从目标项目目录中选取了 6 份 Markdown 文档作为分析语料，总字符量约 16 KB。这 6 份文件的主题围绕课程实验报告的生成流程展开：一份主技能定义文件（SKILL.md，159 行）规定了报告生成的完整工作流和写作约束；一份项目说明文件（README.md）概括了技能的使用方式和依赖；四份参考文件分别覆盖材料恢复、证据支撑、报告结构和最终审阅四个子主题。

\section{方法与实现}

\subsection{文本收集与预处理}

我们从目标目录递归扫描了所有以 \texttt{.md} 为扩展名的文件。扫描路径排除了隐藏目录和输出目录，前者是为了避免扫描版本控制或临时缓存中的非语料文件，后者则是为了防止分析过程中产生的 CSV 和 PNG 等输出文件被循环纳入输入。每个文件以 UTF-8 编码读取，对偶发的解码错误使用替换策略以保证流程的连续性，确保不会因个别字符的编码问题而中断整个语料的处理。

\subsection{分词策略}

我们采用了双路径的分词设计。在默认路径中调用 jieba 分词库对全文进行切分。jieba 能够同时识别中文词语和英文单词，内置词典对常见中文词汇的覆盖较为完整，对中英混合文本的适应性优于纯规则方法。同时我们准备了正则表达式回退路径：若 jieba 在目标环境中不可用，则退而使用正则表达式按字母和数字序列提取英文单词并统一转为小写，确保流程在无第三方库的环境下仍可运行。分词完成后，我们对结果进行停用词滤除，将 the、a、is、of、in 等英文高频功能词以及若干中文虚词从统计中移除，以减少它们对实质性内容词的干扰。

分流逻辑的核心代码如清单~\ref{lst:tokenize} 所示。优先路径调用 jieba 的 lcut 方法获得全部分词结果后，遍历每个 token 并按语言类型分别处理：纯英文 token 转为小写，中文 token 保留原样，混合 token 则进一步拆分为子片段。这种按 token 类型分流的设计使得同一语料中的中文词和英文词得到一致的处理，不会因为语言边界而产生分词遗漏。

\begin{lstlisting}[caption={分词函数的分流逻辑}, label={lst:tokenize}]
def tokenize(text: str) -> List[str]:
    try:
        import jieba
        words = jieba.lcut(text)
    except ImportError:
        words = re.findall(r"[a-zA-Z0-9_]+", text.lower())
        return words
    result = []
    for w in words:
        w = w.strip()
        if not w:
            continue
        if re.fullmatch(r"[a-zA-Z0-9_]+", w):
            result.append(w.lower())
        elif re.search(r"[\u4e00-\u9fff]", w):
            w_clean = re.sub(r"[^\u4e00-\u9fff]", "", w)
            if w_clean:
                result.append(w_clean)
        else:
            sub = re.findall(r"[a-zA-Z0-9\u4e00-\u9fff]+", w)
            result.extend(s.lower() if s.isascii() else s for s in sub)
    return result
\end{lstlisting}

\subsection{统计量与分析方法}

在分词结果之上，我们计算了以下统计量。

词频：使用 Python 标准库 collections.Counter 对全部 token 进行计数并按频次降序排列。同时我们按文件分组计数，得到每份文档独立的词频分布。单文件词频的意义在于，它能够揭示每份文件的内容焦点：一份以"如何审阅报告"为主题的 Markdown 文档，其高频词将与一份以"如何恢复材料"为主题的文档呈现显著差异。

N-gram 词组频率：我们通过滑窗方式分别提取了二元词组（bigram）和三元词组（trigram）。整个语料被视为一个连续的 token 序列进行滑窗，不作句子边界截断。这样处理的原因是该语料的 Markdown 格式中包含大量跨自然段落的列表项和代码块标记，强行按句子边界截断反而会切断这些格式元素与其上下文之间的搭配关系。

TF-IDF 关键词：我们对每份文档独立计算词频（TF），并在语料层面计算逆文档频率（IDF），使用带平滑的公式 \( \text{TF} \times \log(N / (1 + \text{DF})) \)，其中 \(N\) 为文档总数，DF 为包含该词的文档数。分母中的 \(+1\) 是标准的加一平滑处理，用于避免极端情况下除零错误。在一个仅含 6 份文档的小语料中，TF-IDF 对分布极端不均匀的词格外敏感：某词只要在一份文档中高频出现而在其余五份中完全缺席，其 IDF 就会接近理论最大值。这一特性使 TF-IDF 成为识别"文件标志词"的有效工具。

清单~\ref{lst:tfidf} 展示了简化 TF-IDF 的计算实现。

\begin{lstlisting}[caption={简化 TF-IDF 计算}, label={lst:tfidf}]
def compute_tf_idf(docs: List[List[str]]) -> Dict[str, float]:
    from math import log
    N = len(docs)
    df = Counter()
    for doc in docs:
        df.update(set(doc))
    tf_idf = {}
    for doc in docs:
        for word in set(doc):
            tf = doc.count(word) / len(doc) if doc else 0
            idf = log(N / (1 + df[word]))
            tf_idf[word] = tf_idf.get(word, 0) + tf * idf
    return tf_idf
\end{lstlisting}

Zipf 定律验证：我们将去停用词后的词频按排名降序排列，在双对数坐标系下进行线性拟合。拟合斜率直接反映了词频分布的幂律衰减程度，理想 Zipf 分布的斜率为 \(-1\)。同时我们计算了累积覆盖率曲线，以量化"多少比例的高频词覆盖了语料中总 token 的多少比例"。

\subsection{可视化方案}

我们使用 matplotlib 生成全部图表，中文字体设置为文泉驿正黑。词云使用 wordcloud 库生成，通过 font\_path 参数指定字体文件路径以确保中文正常渲染。所有图表统一以 180 dpi 的 PNG 格式保存，以确保在 LaTeX 编译时有足够的显示精度。

\section{结果分析}

\subsection{主题词的集中度与文件结构的关系}

词频 Top10 中，「实验」以 88 次位居首位，远高于第二名「报告」的 70 次。这个差距（18 次）本身就能提供信息。「实验」之所以能够独占高位，是因为它在整个技能文档体系中扮演了"主语"级别的角色：实验报告是技能的产出物，无论是方法的描述、材料的准备还是结果的呈现，都围绕着"实验"展开；而"报告"是实验的产出形式，其出现场景相对收敛于描述结构和审阅标准的段落。这种"主语"与"宾语"的频次级差，反映了该技能文档以"实验"为驱动核心、以"报告"为目标载体的内容架构。

SKILL.md 作为语料中篇幅最大（8,390 字符）且内容覆盖面最广的文件，对全局词频分布有决定性影响。它在全局 Top10 的 8 个词上的贡献均为各文件之首，只在「证据」（evidence-grounding.md 贡献最大）和「用户」（final-review.md 中约束语句密集出现）两个词上退居次席。这一文件的主导性在热力图中表现为 SKILL.md 列的深色块密度远高于其他五列。它不仅是词频的贡献者，更是整个语料主题统一性的锚点。

\subsection{Zipf 斜率偏离的结构性原因}

拟合斜率 \(-0.879\) 与理论值 \(-1.0\) 的偏离方向为"绝对值偏小"，即词频随排名下降的速度比 Zipf 定律预测得慢。造成这一偏离的主要原因是该语料的内容词分布特性。该语料中前几位的词全部是内容词，包括「实验」「报告」「材料」「教师」等。内容词的频次分布不是由语法的强制频率决定的，而是由语义主题的覆盖密度决定的。一个 159 行的技能文件能容纳"实验"一词的次数不可能无限增长，因为每个段落中该词作为主题词出现一到两次就达到了自然的信息密度上限。这形成了内容词的一个"内在天花板"：频次上不去，但排名靠后的内容词频次又不会跌得太快，因为每个语义方面都需要一定的最低出现次数来维持可读性。结果就是排名-频次曲线在头部被压低、在中段又降得不够快，整体斜率趋于 \(-0.88\) 而非 \(-1.0\)。

\subsection{累积覆盖率的"词汇高原"现象}

Top100 覆盖率达到 42.9\%，向 50\% 推进的速度在约第 50 位之后显著放缓。这一放缓不是个别异常点造成的，而是该语料中一个结构性的"词汇高原"造成的：排名约第 50 位到第 300 位之间存在大量频次在 4 至 8 次之间的中频词，每个词贡献的覆盖率增量不足 0.1 个百分点，但词的数量众多。这些中频词的来源是技能文档中包含的大量具体术语，如"编译""审阅""清单""交付""审计""合规"等。每个词都在特定的任务或约束条款中有若干次重复出现，但受限于它们所描述的子主题的篇幅，无法达到高频主题词那样的频次。这个词汇高原是该语料作为规范性文档集合的结构特征：一个核心主题被拆解为大量子条款，每个子条款贡献一组中频词，这些中频词共同构成了一条缓慢爬升的覆盖率曲线。

\section{结论}

我们通过本次实验对 6 份 Markdown 技能文档实施了系统的词频统计分析，建立了覆盖词频、N-gram 词组频率、TF-IDF 关键词和 Zipf 定律验证的多维度分析框架。

该语料的词频分布在整体上服从 Zipf 定律的幂律衰减，拟合斜率为 \(-0.879\)，中段数据（约第 10 至第 400 位）呈现稳定的幂律行为。斜率偏离理想值 \(-1.0\) 的原因是语料中所有高频词均为内容词而非功能词，内容词的频次受语义覆盖密度的天然限制，无法拉开通用语料中功能词层级间的那种数量级差距。累积覆盖率分析表明，前 100 个高频词覆盖了语料 42.9\% 的内容，覆盖率爬升缓慢的主要原因是排名第 50 至第 300 位之间存在大量中频词构成的"词汇高原"，这是规范性文档被拆分为大量子条款后产生的结构性特征。

语料的内部结构呈现出三个层次：SKILL.md 作为核心文件在几乎所有主题词上贡献最大，确立了语料的主题统一性；README.md 以中文叙述搭配英文技术标签的模式构成了独立的信息层次；四份参考文件则各自以其局部高频词反映了不同的功能侧重点：final-review.md 侧重删除与审阅，evidence-grounding.md 侧重证据与声称，source-recovery.md 侧重代码命令模板。N-gram 分析进一步揭示了规范性文档的文体特征：「而 非」作为排除性修辞标记以 26 次的最高频次出现在 bigram 中，折射出技能文件以否定式约束密集驱动的写作风格。

我们建立的文本分析流水线仅依赖 Python 标准库和少量第三方包即可完成从原始 Markdown 文档到多维统计图表的全流程分析，对 6 份文档共 5,719 个有效 token 的语料表现出了充分的统计敏感性，能够识别词频分布中的结构特征、文件间的主题差异和 N-gram 层面的文体规律。
